## Общие требования
- [x] После рефакторинга приложение соответствует дизайну и функциональным требованиям

## Плейсхолдер (нет результатов)
- [x] Если API-запрос выполнен успешно, но аудиозаписи не найдены:
    - [x] Отображается изображение-заглушка
    - [x] Отображается сообщение о пустом результате поиска

## Плейсхолдер (ошибка сервера)
- [x] Если API-запрос завершился с ошибкой:
    - [x] Отображается изображение-заглушка
    - [x] Отображается сообщение об ошибке сервера
    - [x] Отображается кнопка «Обновить»

## Кнопка «Обновить»
- [x] При нажатии выполняется повтор последнего неудачного API-запроса

## Непустой результат запроса
- [x] Если сервер вернул хотя бы одну песню:
    - [x] Отображается список результатов поиска

## Элемент списка результатов
- [x] Каждый элемент списка содержит:
    - [x] Обложку трека
    - [x] Название трека (`trackName`)
    - [x] Имя исполнителя (`artistName`)
    - [x] Продолжительность в формате `mm:ss` (из `trackTimeMillis`)

## Обложка трека
- [x] Используется изображение из `artworkUrl100`

### Плейсхолдер обложки
- [x] Если обложка отсутствует:
    - [x] Отображается изображение-заглушка
- [x] Если обложка ещё не загружена:
    - [x] Отображается изображение-заглушка

### Загруженная обложка
- [x] Если изображение успешно загружено:
    - [x] Отображается обложка трека

## Кнопка «Очистить поисковый запрос»
- [x] При наличии текста в поиске и списка результатов:
    - [x] Кнопка «Очистить» отображается
- [x] При нажатии:
    - [x] Поле поиска очищается
    - [x] Клавиатура скрывается
    - [x] Кнопка (x) исчезает
    - [x] Список треков исчезает
