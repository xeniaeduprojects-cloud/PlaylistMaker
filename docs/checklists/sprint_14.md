# Чеклист требований

## Экран «Поиск»

### Debounce для поискового запроса
- [x] Поисковый запрос выполняется автоматически (без нажатия Done), через 2 секунды после ввода последнего символа
- [x] Реализован debounce по аналогии с примером из предыдущей темы

### Индикатор загрузки
- [x] С момента отправки запроса до получения ответа от сервера отображается ProgressBar
- [x] ProgressBar корректно отображается в светлой теме
- [x] ProgressBar корректно отображается в тёмной теме

### Debounce для элементов списка
- [x] Реализован debounce на нажатие элемента списка результатов поиска
- [x] Одновременное открытие нескольких аудиоплееров исключено

## Экран «Аудиоплеер»

### Модель данных
- [x] В класс `Track` добавлено поле `previewUrl: String`
- [x] Поле `previewUrl` корректно парсится из ответа iTunes Search API

### Воспроизведение
- [x] Воспроизведение отрывка трека реализовано через `MediaPlayer`
- [x] Управление воспроизведением осуществляется кнопкой в центре экрана

### Кнопка «Играть / Пауза»
- [x] Если воспроизведение не идёт — отображается кнопка «Играть»
- [x] Если воспроизведение идёт — отображается кнопка «Пауза»
- [x] При нажатии «Играть» — начинается воспроизведение, кнопка меняется на «Пауза»
- [x] При нажатии «Пауза» — воспроизведение приостанавливается, кнопка меняется на «Играть»

### Логика начала воспроизведения
- [x] Если воспроизведение ещё не начиналось — отрывок играет с начала
- [x] Если отрывок был проигран полностью — повторное нажатие начинает с начала
- [x] Если воспроизведение было на паузе и отрывок не закончился — продолжается с места остановки

### Прогресс воспроизведения
- [x] Текущее время воспроизведения отображается в формате `mm:ss`
- [x] Обновление времени реализовано через `Handler`
- [x] Обновление времени привязано к управлению воспроизведением (старт/пауза)
- [x] Значение продолжительности трека остаётся неизменным (не отражает прогресс)
- [x] При паузе обновление времени останавливается
- [x] При окончании отрывка время сбрасывается на `00:00`

### Завершение воспроизведения
- [x] Когда отрывок заканчивается — воспроизведение останавливается
- [x] Кнопка «Пауза» меняется на «Играть»
- [x] Обновление прогресса останавливается и сбрасывается на `00:00`

### Навигация назад
- [x] При нажатии системной кнопки «Назад» во время воспроизведения — воспроизведение останавливается
- [x] При нажатии навигационной кнопки «Назад» во время воспроизведения — воспроизведение останавливается
- [x] Пользователь возвращается на предыдущий экран

### Фоновый режим
- [x] При переводе приложения в фон во время воспроизведения — воспроизведение приостанавливается
- [x] Кнопка «Пауза» меняется на «Играть»
- [x] Обновление прогресса останавливается
