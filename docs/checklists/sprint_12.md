# Критерии успешного выполнения задания

## UI истории поиска

- [x] Отображается заголовок «Вы искали» (при непустой истории и пустом поле поиска в фокусе)
- [x] Отображается список ранее просмотренных треков
- [x] Отображается кнопка «Очистить историю»
- [x] Треки хранятся в порядке добавления (новые — сверху)
- [x] В истории хранится не больше 10 треков
- [x] Если трек уже есть в истории, он перемещается в верхнюю часть списка, а предыдущая запись удаляется
- [x] При вводе текста в поле поиска отображается иконка очищения поля

## UI элементов списка истории поиска

- [x] Отображается область для обложки трека
- [x] Отображается название трека (`trackName`)
- [x] Отображается имя исполнителя (`artistName`)
- [x] Отображается продолжительность трека в формате `mm:ss` (`trackTimeMillis`)
- [x] В качестве обложки используется изображение по ссылке `artworkUrl100`

## Плейсхолдер обложки трека

- [x] Если у трека нет изображения обложки — отображается изображение-заглушка
- [x] Если обложка есть, но ещё не загружена — отображается изображение-заглушка

## Изображение обложки трека

- [x] Если обложка есть и загружена — отображается в области для обложки

## Нажатие на кнопку «Очистить историю»

- [x] История просмотренных треков удаляется
- [x] Список треков исчезает
- [x] Кнопка «Очистить историю» исчезает
- [x] Заголовок «Вы искали» исчезает

## Тема приложения

- [x] Текущая настройка темы (светлая/тёмная) сохраняется в `SharedPreferences`
- [x] Тема загружается из `SharedPreferences` при каждом запуске приложения
- [x] Переключатель темы на экране «Настройки» корректно работает
