# Экран «Аудиоплеер» — Чеклист требований

## Переход на экран «Аудиоплеер»

- [x] Нажатие на трек в списке результатов поиска переводит пользователя на экран «Аудиоплеер»
- [x] Нажатие на элемент истории поиска переводит пользователя на экран «Аудиоплеер»
- [x] Если приложение было переведено в фоновый режим на экране «Аудиоплеер», то после восстановления пользователь видит экран «Аудиоплеер»

## Переход на предыдущий экран

- [x] Нажатие на системную кнопку «Назад» возвращает пользователя на предыдущий экран
- [x] Аналогичный жест «назад» возвращает пользователя на предыдущий экран

## UI-элементы экрана аудиоплеера

- [ ] Отображается кнопка «Назад» (нажатие эквивалентно системной кнопке «Назад»)
- [ ] Отображается область для обложки плеера
- [ ] Отображается название трека (`trackName`)
- [ ] Отображается имя исполнителя (`artistName`)
- [ ] Отображается название альбома (`collectionName`) *(если есть)*
- [ ] Отображается год релиза трека (`releaseDate`) *(если есть)*
- [ ] Отображается жанр трека (`primaryGenreName`)
- [ ] Отображается страна исполнителя (`country`)
- [ ] Отображается продолжительность трека в формате `mm:ss` (`trackTimeMillis`)
- [ ] Отображается кнопка добавления в плейлист
- [ ] Отображается кнопка добавления в избранное
- [ ] Отображается кнопка контроля воспроизведения
- [ ] Отображается прогресс воспроизведения в формате `mm:ss` (под кнопкой контроля воспроизведения)

## Плейсхолдер обложки

- [ ] Если у трека нет изображения обложки, отображается изображение-заглушка
- [ ] Если у трека есть обложка, но она ещё не загружена, отображается изображение-заглушка

## Изображение обложки

- [ ] Если у трека есть обложка и она загружена, изображение отображается в области обложки
- [ ] Обложка загружается по ссылке `artworkUrl100` с заменой последней части ссылки: `100x100bb.jpg` → `512x512bb.jpg`
- [ ] Пока изображение высокого разрешения загружается, отображается изображение-заглушка

---

> **Пример ссылки на обложку:**
> `https://is5-ssl.mzstatic.com/image/thumb/Music125/.../100x100bb.jpg`
> → заменить на →
> `https://is5-ssl.mzstatic.com/image/thumb/Music125/.../512x512bb.jpg`
